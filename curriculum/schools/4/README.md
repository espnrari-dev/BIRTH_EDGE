# SCHOOL 4 - Dynamical Systems & Cybernetics - Central discipline
Dynamical Systems: state, transitions, trajectories, phase space, equilibria, stability, nonlinear, discrete/continuous - Lab AEGIS
Differential Equations: ODEs, nonlinear ODEs, numerical integration, RK4, coupled systems, parameter estimation - Lab Duffing/ODE discovery
System Identification: Given observations, can we infer hidden rules governing it? parameter estimation, model selection, structural identification, observability, identifiability, latent variables - Connects directly to AEGIS
Cybernetics: feedback, control, regulation, homeostasis, adaptation, goal-directed behavior, closed-loop, self-regulation - Labs SHOGUN, T-PRAO L4, ORGANISM, homeostat
Autonomous System Theory: distinction automation vs autonomy, formalize Observation→internal state→interpretation→decision→action→environmental response→updated state - central mathematical object
