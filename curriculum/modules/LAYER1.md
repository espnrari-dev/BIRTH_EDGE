# LAYER 1 - Learner Curriculum - For someone who knows little
Progressive:
1. Thinking in Systems: What is system? State, inputs, outputs, feedback, Deterministic vs adaptive, Why architecture matters
2. Building From Nothing: Python fundamentals, Linux/Termux, Files/processes/databases, APIs real-world data, Building functioning organism rather than isolated scripts
3. Memory and Persistence: State, Ledgers, Hash chains, Persistent learning, Recovery after termination
4. Observation → Decision → Action: Sensors, Feature extraction, Rules, Decision engines, Confidence, Feedback loops
5. Adaptive Intelligence: Online learning, Logistic regression, Incremental learning, Experience-based adaptation, Why model that merely predicts isn't necessarily adaptive system
6. Self-Evaluation: Designing experiments, Controls, Ablations, Held-out testing, Identifiability, Persistence tests, Failure analysis
7. Autonomous Architecture: Watchers, Supervisors, Heartbeats, Runtime state, Governance, Safety boundaries, Closed-loop operation
8. Novel-System Investigation: How to distinguish implementation from idea, Architecture vs components, Prior-art investigation, What "novel" can and cannot mean scientifically, How to document original architecture
9. Real-World Deployment: Operating on phone, Resource constraints, Real data, Logging, Monitoring, Reliability, Long-running operation
10. From Prototype to Professional System: Reproducibility, Documentation, Testing, Versioning, Evidence packages, Demonstrations, Commercialization
